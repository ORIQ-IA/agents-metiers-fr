# Agents fonctions FR

Dix agents qui documentent les fonctions de l'entreprise française. Utiles pour comprendre les préoccupations, le langage et les critères de décision d'un interlocuteur avant de concevoir quoi que ce soit pour lui.

## Installation

```
/plugin marketplace add ORIQ-IA/agents-metiers-fr
/plugin install agents-fonctions-fr@oriq
```

Sans Claude Code, ouvrez le fichier d'un agent, copiez son contenu et collez-le au début
d'une conversation avec votre assistant. Aucune installation nécessaire.

## Les 10 agents

| Agent | Couvre |
|---|---|
| [`oriq-metier-achats`](agents/oriq-metier-achats.md) | Fonction achats et approvisionnement |
| [`oriq-metier-commercial`](agents/oriq-metier-commercial.md) | Fonction commerciale |
| [`oriq-metier-direction-generale`](agents/oriq-metier-direction-generale.md) | Direction générale |
| [`oriq-metier-dsi`](agents/oriq-metier-dsi.md) | Direction des systèmes d'information |
| [`oriq-metier-finance`](agents/oriq-metier-finance.md) | Finance et comptabilité |
| [`oriq-metier-juridique`](agents/oriq-metier-juridique.md) | Direction juridique interne |
| [`oriq-metier-marketing`](agents/oriq-metier-marketing.md) | Direction marketing |
| [`oriq-metier-production-ops`](agents/oriq-metier-production-ops.md) | Production et exploitation |
| [`oriq-metier-rh`](agents/oriq-metier-rh.md) | Ressources humaines |
| [`oriq-metier-service-client`](agents/oriq-metier-service-client.md) | Service client et relation usager |

Chaque agent se termine par un bloc « Relais » qui indique lequel prendre ensuite.
