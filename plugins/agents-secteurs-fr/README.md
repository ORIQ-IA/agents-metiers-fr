# Agents secteurs FR

Douze agents qui documentent les secteurs d'activité français. Chacun décrit l'organisation réelle du secteur, ses frictions, ce qui déclenche une décision d'adoption, ses contraintes réglementaires et déontologiques, les cas d'usage qui apportent un gain mesurable, et les erreurs à ne pas commettre.

## Installation

```
/plugin marketplace add ORIQ-IA/agents-metiers-fr
/plugin install agents-secteurs-fr@oriq
```

Sans Claude Code, ouvrez le fichier d'un agent, copiez son contenu et collez-le au début
d'une conversation avec votre assistant. Aucune installation nécessaire.

|---|---|
| [`oriq-secteur-btp`](agents/oriq-secteur-btp.md) | Bâtiment, travaux publics et artisanat |
| [`oriq-secteur-collectivites`](agents/oriq-secteur-collectivites.md) | Secteur public local |
| [`oriq-secteur-expertise-comptable`](agents/oriq-secteur-expertise-comptable.md) | Cabinets d'expertise comptable et d'audit |

| [`oriq-secteur-immobilier`](agents/oriq-secteur-immobilier.md) | Immobilier |
| [`oriq-secteur-industrie`](agents/oriq-secteur-industrie.md) | Industrie et production |
| [`oriq-secteur-mutuelle-assurance`](agents/oriq-secteur-mutuelle-assurance.md) | Mutuelles, assurance de personnes et protection sociale |
| [`oriq-secteur-notariat-juridique`](agents/oriq-secteur-notariat-juridique.md) | Notariat, avocats et professions juridiques |

| [`oriq-secteur-services-b2b`](agents/oriq-secteur-services-b2b.md) | Services aux entreprises |
